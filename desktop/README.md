# Music Remover для компьютера

Приложение для macOS (позже и для Windows): перетаскиваете видео или аудио, получаете копию без фоновой музыки. Голос остаётся.
Работает без интернета, на видеокарте. Модель та же, что в расширении: UVR MDX-Net «Kim Vocal 2».

## Как пользоваться

1. Откройте **Music Remover**.
2. Перетащите файлы в окно (или нажмите «выберите файлы»). Можно сразу несколько, можно целую папку.
   Ещё варианты: перетащить файлы на иконку в Dock или выбрать «Открыть с помощью → Music Remover» в Finder.
3. Готовый файл появится **рядом с оригиналом** с припиской «(без музыки)», например `Лекция (без музыки).mp4`.
   Папку для готовых файлов можно сменить внизу окна.

Что происходит с файлом:
- **Видео не перекодируется**: картинка копируется побайтно, качество не меняется. Заменяется только звук.
- Формат сохраняется: MP4 → MP4, MKV → MKV, MP3 → MP3, WAV → WAV и т. д.
  WMV и WMA записываются в MKV и M4A соответственно (в исходный формат FFmpeg пишет плохо).
- Сохраняются субтитры, обложка MP3, главы, метаданные, язык звуковой дорожки, частота дискретизации (вплоть до 96 кГц) и моно/стерео.
- Объёмный звук 5.1 сводится в стерео: модель работает со стерео.
- Длина файла не ограничена: звук обрабатывается кусками, память не растёт.

Интерфейс на русском и английском (переключатель RU/EN). Приписка к имени файла зависит от языка: «без музыки» / «no music».

## Требования

- macOS 14+ на Apple Silicon (на Intel будет работать на процессоре, медленнее).
- **FFmpeg**: `brew install ffmpeg`. Пока он не входит в приложение (см. «Что дальше»).

## Замеры (MacBook, Apple Silicon, CoreML)

| Что | Результат |
|---|---|
| Скорость, видеокарта (CoreML) | **17–20× быстрее реального времени**: 20 мин видео за 61 с |
| Скорость, процессор (запасной вариант) | ~1,4× реального времени |
| Качество (SDR на речи с известным эталоном) | **22,6–22,9 дБ** (в расширении ~21 дБ) |
| Видео NASA с дикторским текстом | там, где звучит только музыка, она тише на **25 дБ** |
| Память | ~700 МБ независимо от длины файла |
| Первый запуск модели | ~3,5 с (дальше модель остаётся в памяти) |

## Сборка

```bash
cd desktop
npm install            # Tauri CLI
npm test               # юнит-тесты + полный прогон на сгенерированном видео
npm run build          # → target/release/bundle/macos/Music Remover.app и .dmg
```

Нужны Rust (`brew install rustup && rustup default stable`), Node, FFmpeg и модель `../models/Kim_Vocal_2.onnx`
(`npm run fetch-model` в корне репозитория).

Консольная утилита для проверки без интерфейса:

```bash
cargo run -p mr-core --release --bin mr-cli -- [--cpu] [--suffix "без музыки"] файл1.mp4 файл2.mp3
```

## Устройство

```
desktop/
  core/        Rust-ядро (общее для macOS и Windows)
    mdx.rs     STFT/iSTFT для модели (перенос src/core/mdx.ts из расширения)
    model.rs   ONNX Runtime: CoreML (macOS) / DirectML (Windows) / CPU
    media.rs   FFmpeg: разбор файла, выбор формата и кодека, имя результата
    job.rs     конвейер: FFmpeg-декодер → куски по 5,75 с → модель → FFmpeg-кодер (+ копия видео)
  app/         Tauri-приложение: очередь файлов, фоновый поток, события прогресса
  ui/          интерфейс (HTML/CSS/JS, без сборщика), RU/EN
```

Интерфейс можно посмотреть в обычном браузере: `python3 -m http.server -d ui` → откроется демо с примерами строк.
